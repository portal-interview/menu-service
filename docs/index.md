# Menu Service

Every legendary meal starts with a LEGENDARY MENU! This service is where the flavor lineup lives.

The Menu Service manages all menu content across Flavortown. Creating menus, adding items, updating prices, managing categories, tracking allergens — if it's on the menu, it lives here. From Trash Can Nachos to the Donkey Sauce Burger, every item is managed through this service.

## Features

- **Multi-menu support** — Seasonal menus, daily specials, permanent classics
- **Category management** — Appetizers, mains, sides, desserts, drinks
- **Allergen tracking** — Full allergen information for every item
- **Availability control** — 86 items in real-time when ingredients run out

## Consumers

The Flavor Portal, Burger Builder, and Triple D Mobile all consume menu data from this service. When a menu changes, all frontends update in real-time.
